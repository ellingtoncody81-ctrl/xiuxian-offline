# 如何组装出可运行的离线版

> **本仓库不提供任何游戏资源，也不提供获取渠道。**
> 下面所有输入都需要**你自己合法持有**。

## 你需要准备
| 输入 | 说明 |
|---|---|
| 官方 **H5 客户端构建** | 静态资源目录（含 `index.html`、`assets/scriptAsset/index.js` 等） |
| 官方 **服务端发布包** | 含编译产物 `dist/` 与依赖目录（Node 运行所需） |
| Node 运行时 | 启动器依赖（Electron 随包分发） |

## 组装步骤
```bash
python tools/build_package.py   --client  "<你的客户端构建目录>"   --backend "<你的服务端发布包目录>"   --out     "./dist-ready"
```
脚本会：
1. **校验**输入结构与关键文件（版本/尺寸指纹不符会明确报错，不会静默产出坏包）
2. 复制客户端与服务端到输出目录
3. 按 `patches/` 的规则施加改动（锚点替换/插入，**不含原版文件**）
4. 把 `shim/`、`launcher/` 接入启动链路，生成 `启动.bat`
5. 打印输出结构与自检结果

**脚本全程离线**：不访问网络、不下载任何东西。

## 常见问题
- **报"客户端版本不符"**：你的客户端构建与我改造时用的版本不同 ⇒ 需要在 `patches/` 里对齐锚点
- **启动后白屏**：多数是客户端静态目录没指对，或 shim 未加载（看控制台 `SOLO_READY`）
- **AI 说话很怪/不讲话**：根目录 `ai-config.json` 未填 `key` ⇒ 退回内置台词库是正常行为
