# 怎么把它搭起来（手动步骤）

> **本仓库不提供、也不链接任何游戏资源。** 下面的输入都需要**你自己合法持有**：
> 这类资源在淘宝、闲鱼等平台上有人转售整包，玩家社群里也时有流传 ——
> 本仓**只说明渠道类型，不给任何链接 / 店铺 / 联系方式**，也不评判其合法性。

## 一、你需要准备
| 输入 | 说明 | 缺失后果 |
|---|---|---|
| 官方 **H5 客户端构建** | 静态资源目录（含 `index.html`、`assets/scriptAsset/index.js`、`cocos2d-js-min.js`） | 没画面 |
| 官方 **服务端发布包** | 含编译产物 `dist/`（`app.js`、`src/`、`common/excel/`、`node_modules/`） | 没后端，登录即失败 |
| Node 运行时 | 启动器依赖（Electron 随启动器一起装） | 起不来 |

## 二、目标目录长这样
```
<你的运行目录>/
  www/                       ← 官方 H5 客户端构建（按 改造点清单 的 9 处改）
  app/
    main.js preload.js inject.js local-server.js account.html package.json
    backend/
      dist/                  ← 官方服务端 dist（按 改造点清单 的 18 处改）
        _solo_*.js           ← 本仓 shim/ 的 11 个模块（整个放平到 dist/ 根）
        src/util/redis.js    ← 用 shim/server_overrides/ 的同名文件覆盖
        src/util/mongodb.js  ← 同上
    db/                      ← JSON 存档（首次运行自动建 + 备份）
  launch.bat                 ← 双击启动
```

## 三、步骤
1. 把官方客户端构建拷成 `www/`，按 [改造点清单](改造点清单.md) §一 改那 9 个文件
2. 把官方服务端 `dist/` 整个拷到 `app/backend/dist/`
3. 按清单 §二 改那 18 个文件（改动点都带注释标记，可搜 `[solo` / `[v4.` / `单机版`）
4. 用 `shim/server_overrides/src/util/*.js` 覆盖对应的官方文件（存储层换成 JSON 版）
5. 把本仓 `shim/*.js`（11 个）拷到 `app/backend/dist/` 根目录
6. 把本仓 `launcher/*` 拷到 `app/`，然后 `cd app && npm i`
7. 双击 `launch.bat`（内部设 `ELECTRON_RUN_AS_NODE=` 后 `npx electron .`）
8. 可选：把 `ai-config.example.json` 复制成根目录 `ai-config.json` 并填 key（不填 = 离线台词库模式）

## 四、几个必须知道的坑
- **`ELECTRON_RUN_AS_NODE`**：本机全局若设了这个变量，Electron 会当 Node 跑 → 启动即崩（`app` undefined）。启动脚本里必须清掉它
- **存储层**：不换 `redis.js` / `mongodb.js` 的话，服务端会去连不存在的 Redis / Mongo → 启动就挂。这两份是本改造的核心之一
- **数据目录**：`_solo_boot.start({dbDir})` 用 `SOLO_DB_DIR` 决定存档位置；启动时会自动备份到 `db-backups/<时间戳>/`
- **不联网**：整套东西没有对外请求（除了你自己配的 AI 接口）

## 五、常见问题
- **启动后白屏**：客户端静态目录没指对，或 shim 没加载（主进程日志里能看到 `SOLO_READY <port>`）
- **登录报错/黑屏但有声音**：多半是服务端某个榜单/列表数据脏了 → 看服务端 stderr（响应体只有一行提示，堆栈在 stderr）
- **AI 说话很怪 / 不讲话**：根目录 `ai-config.json` 没填 `key` ⇒ 退回内置台词库，属正常行为
